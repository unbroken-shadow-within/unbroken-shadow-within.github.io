# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This is the **GitHub Pages deployment target** for the web build of *UNBROKEN · Shadow Within*, a
Godot 4.7 game by usw-gametech. It contains only exported artifacts, not the game's source. The
Godot project (scenes, `scripts/`, `addons/`, `assets/`, `tools/`) lives in a separate repository;
paths like `scripts/ui/legal.gd` in `THIRD_PARTY_NOTICES.md` refer to that project, not to files here.

Every commit on `main` is a `Web build <source-hash>` export; the hash is the commit of the game's
source repo that was exported. A build normally touches only `index.html`, `index.pck`,
`m/index.html` and `m/index.pck` (the `fileSizes` entries in `GODOT_CONFIG` change with the `.pck`).
Do not hand-edit `index.js`, `*.wasm`, `*.pck` or the audio worklets: they are generated by the Godot
exporter and will be overwritten by the next export.

## Layout: two exports of the same game

| | Root (`/`) | `m/` |
|---|---|---|
| Target | desktop browsers | phones / tablets |
| Engine | `index.wasm` (small main module) + `index.side.wasm` (dynamic-linked side module) | single monolithic `index.wasm` |
| GDExtensions | `libeffekseer.nothreads.wasm` (Effekseer VFX runtime) | none (`gdextensionLibs: []`) |
| Threads | `GODOT_THREADS_ENABLED = false` | same |

The root `index.html` has an inline redirect script (the only line that differs from `m/index.html`
besides `GODOT_CONFIG`): iPhone/iPad/Android user agents, and iPad-as-Macintosh with touch, are sent
to `m/` with the query string and hash preserved. Query overrides: `?desktop=1` stays on the root
build, `?mobile=1` forces the `m/` build. Both pages also push a dummy history entry so the browser
back button does not leave the game.

Both pages set `ensureCrossOriginIsolationHeaders: true`; because threads are disabled the
service-worker fallback is only attempted if `Engine.getMissingFeatures` reports something missing.
`.nojekyll` must stay so GitHub Pages serves the files verbatim.

## Running locally

There is no build, lint or test step here. Serve the directory statically and open it in a browser:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/` (desktop build) or `http://localhost:8000/m/` (mobile build).
Opening `index.html` via `file://` does not work (WASM/fetch restrictions).

## Licensing

The game itself is proprietary (`LICENSE`, English and Thai). `THIRD_PARTY_NOTICES.md` lists the
engine, addons, fonts, music, sprites and sound effects with their licences; it is meant to stay in
step with the in-game credits screen. If you change the notices here, the same change must be made
in the game's source repo (and vice versa). The notices flag one set of sound effects (Blade Assault)
whose permission is not yet confirmed.
